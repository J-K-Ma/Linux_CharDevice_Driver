# Linux_CharDevice_Driver
This is an industrial-grade generic character device framework for Linux kernel 4.1.15, referenced from kernel source code. It improves error handling for each function and implements driver multi-instantiation via platform driver and device tree. The code separates the work done in module init and probe functions, including class creation, dynamic devid allocation, cdev setup, device node generation and layered error rollback. Corresponding resource release is implemented in remove function to prevent memory leaks. This clean-structured driver is great for learning character device development and understanding multi-instantiation.
